# 데이터 무결성과 통계적 가설 검정

## 데이터 무결성(Data Integrity)

데이터가 정확하고 일관된 상태를 유지하도록 하는 개념

### 개체 무결성(Entity Integrity)

테이블의 각 행을 서로 구별할 수 있어야 한다는 원칙

- 기본키(Primary Key)를 이용한 데이터 식별
- 기본키의 중복 불가
- 기본키의 NULL 값 불가

즉, **모든 데이터가 고유하게 식별 가능한 상태**

### 참조 무결성(Referential Integrity)

서로 관련된 테이블 사이의 관계가 일관성을 유지해야 한다는 원칙

외래키(Foreign Key)가 참조하는 값은 원칙적으로 참조 대상 테이블에 존재해야 하는 구조

---

# 통계적 가설 검정

데이터에서 관찰된 차이가 우연에 의한 것인지, 통계적으로 의미가 있는지를 판단하는 방법

예시

두 집단의 평균에 차이가 있는지 확인하고 싶은 상황

- **귀무가설(H₀)** → 두 집단의 평균에 차이가 없음
- **대립가설(H₁)** → 두 집단의 평균에 차이가 있음

통계적 검정을 통해 수집된 데이터가 귀무가설과 얼마나 양립하기 어려운지를 평가하고 판단하는 과정

---

## 모수 검정과 비모수 검정

### 모수 검정(Parametric Test)

모집단의 분포에 대해 일정한 가정을 두고 모집단의 모수에 관한 가설을 검정하는 방법

대표적으로 평균과 관련된 검정에 많이 활용

대표적인 방법

- t 검정
- 분산분석(ANOVA)
- 회귀분석의 계수 검정

### 비모수 검정(Non-parametric Test)

모집단의 분포에 대한 강한 가정을 상대적으로 적게 요구하는 검정 방법

데이터가 모수 검정의 가정을 충족하기 어렵거나 순서형 데이터 등에 활용 가능

대표적인 방법

- Mann-Whitney U 검정
- Wilcoxon signed-rank 검정
- Kruskal-Wallis 검정

※ 비모수 검정을 단순히 '중앙값을 검정하는 방법'으로 이해하는 것은 부정확

---

## 데이터가 많으면 모수 검정, 적으면 비모수 검정?

표본의 크기만으로 모수 검정과 비모수 검정을 결정하는 것은 부적절

검정 방법을 선택할 때 고려할 요소

- 분석하려는 가설
- 변수의 측정 수준
- 데이터의 분포
- 이상치 존재 여부
- 표본의 크기
- 독립성 등의 검정 가정

따라서

**데이터가 많음 → 무조건 모수 검정**

**데이터가 적음 → 무조건 비모수 검정**

과 같은 기준으로 결정하지 않는 것이 중요

---

# 정규분포와 중심극한정리

## 정규분포(Normal Distribution)

평균을 중심으로 좌우가 대칭인 종 모양의 확률분포

통계학의 여러 분석 방법에서 중요한 역할을 하는 분포

---

## 중심극한정리(Central Limit Theorem)

일정한 조건에서 표본의 크기가 충분히 커질수록 **표본평균의 분포가 정규분포에 가까워지는 현상**

중요한 점은 원래 데이터 자체가 반드시 정규분포로 변한다는 의미가 아니라는 것

**원자료의 분포 → 정규분포가 된다는 의미 X**

**표본평균의 표집분포 → 정규분포에 가까워진다는 의미 O**

---

# 데이터가 정규분포가 아니라면?

데이터가 정규분포가 아니라고 해서 항상 억지로 정규분포로 변환해야 하는 것은 아님

먼저 분석 방법에서 실제로 어떤 정규성 가정을 요구하는지 확인하는 것이 중요

상황에 따라 고려할 수 있는 방법

- 로그 변환(Log Transformation)
- 제곱근 변환
- 이상치 확인
- 표본 크기와 분석 방법의 강건성 확인
- 비모수 검정 사용
- 다른 통계 모델 선택

즉, **정규분포로 만드는 것 자체가 목적이 아니라 분석 방법에 적합한 접근을 선택하는 것이 목적**

---

# 표본과 샘플링

통계 분석에서는 데이터의 양뿐만 아니라 **표본이 모집단을 얼마나 잘 대표하는지**가 중요

데이터가 매우 많더라도 특정 집단에 편향되어 있다면 잘못된 분석 결과가 발생할 가능성

분석 과정에서 경계해야 할 요소

- 표본 편향(Sampling Bias)
- 선택 편향(Selection Bias)
- 데이터 불균형
- 측정 과정의 오류

---

## 층화추출(Stratified Sampling)

모집단을 특정 특성에 따라 여러 층(Stratum)으로 나눈 뒤 각 층에서 표본을 추출하는 방법

예시

전체 데이터

- A 그룹 60%
- B 그룹 30%
- C 그룹 10%

표본에서도 이 비율을 고려하여 추출하는 방식

모집단에 중요한 하위 집단이 존재할 때 대표성을 확보하는 데 유용

※ 모든 분석에서 무조건 층화추출을 사용해야 하는 것은 아니며 연구 목적과 데이터 구조에 따라 적절한 표본추출 방법 선택

---

# 전수조사와 표본조사

## 전수조사(Census)

모집단에 포함된 모든 대상을 조사하는 방법

표본추출에 따른 오차가 없다는 장점이 있지만 현실에서는 비용, 시간 등의 문제로 실행하기 어려운 경우가 많음

## 표본조사(Sample Survey)

모집단의 일부를 추출하여 조사한 뒤 모집단의 특성을 추론하는 방법

표본을 이용하기 때문에 **표본오차가 발생할 가능성**

따라서 통계에서는 불확실성을 고려한 추론이 중요

---

# 독립표본 t 검정

서로 독립적인 두 집단의 평균을 비교하는 통계적 검정

예시

A 교육을 받은 집단과 B 교육을 받은 집단의 시험 평균 비교

### 기본 가설

**귀무가설(H₀)**  
두 집단의 모집단 평균이 같음

**대립가설(H₁)**  
두 집단의 모집단 평균이 다름

### 고려할 가정

- 관측값의 독립성
- 정규성에 관한 가정
- 사용하는 t 검정 종류에 따른 분산 관련 가정

두 집단의 분산이 동일하다고 보기 어려운 경우 **Welch의 t 검정** 사용 가능

따라서 등분산성이 만족되지 않는다는 이유만으로 반드시 비모수 검정을 선택해야 하는 것은 아님

---

# 대응표본 t 검정

서로 연관된 두 측정값의 평균 차이를 검정하는 방법

대표적인 사례

**동일한 사람의 치료 전 → 치료 후**

한 사람에게서 두 번 측정한 데이터이므로 두 표본이 서로 독립적이지 않은 구조

### 가설

**귀무가설(H₀)**  
두 시점의 평균적인 차이가 없음

**대립가설(H₁)**  
두 시점의 평균적인 차이가 있음

---

# t 검정과 분산분석

## t 검정

주로 두 집단의 평균을 비교하는 방법

## 분산분석(ANOVA)

세 집단 이상의 평균 차이를 검정할 때 사용하는 대표적인 방법

예시

A 치료법 / B 치료법 / C 치료법의 평균 효과 비교

귀무가설

**모든 집단의 모집단 평균이 같음**

대립가설

**적어도 하나의 집단 평균이 다름**

ANOVA에서 유의한 차이가 발견되었다고 해서 어느 집단끼리 다른지 바로 알 수 있는 것은 아니므로 필요한 경우 사후검정(Post-hoc Test) 수행

---

# 카이제곱 검정(Chi-square Test)

범주형 데이터의 빈도와 관련된 가설을 검정할 때 사용하는 방법

예시

성별과 특정 상품 선호 여부 사이에 관계가 있는지 확인하는 상황

t 검정처럼 평균을 비교하는 검정과는 목적이 다른 방법

대표적인 활용

- 적합도 검정
- 독립성 검정

---

# 회귀분석과 독립변수

단순선형회귀의 기본적인 형태

`y = ax + b`

- **x → 독립변수(Independent Variable), 설명변수(Explanatory Variable)**
- **y → 종속변수(Dependent Variable), 반응변수(Response Variable)**
- **a → 회귀계수 또는 기울기**
- **b → 절편**

x의 값이 변할 때 y가 어떻게 변화하는지를 모델링하는 구조

---

## 회귀계수에 대한 가설 검정

단순선형회귀에서 x와 y 사이에 선형적인 관계가 있는지를 확인하기 위해 기울기에 대한 가설 검정 가능

**귀무가설(H₀)**

`a = 0`

x와 y 사이의 선형적인 관계가 없다는 가설

**대립가설(H₁)**

`a ≠ 0`

x와 y 사이에 선형적인 관계가 존재한다는 가설
